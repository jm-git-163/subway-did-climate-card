# subway-did-climate-card

서울 기후동행카드(2024-01-27 도입)가 서울 지하철 이용량을 늘렸는지, 부산 도시철도를 비교집단으로 둔 이중차분(DiD)으로 추정하는 프로젝트.
오픈소스 AI·SW 활용 인재 양성 과정 특화형 2차 (에이전틱 AI x 데이터) 멘티 활동의 일부로 진행합니다.

- [x] 결과 리포트 ([REPORT.md](REPORT.md))

## 결과 요약 (자세한 내용은 REPORT.md)
- 주 추정: 서울 x 도입 후 = +0.12% (95% 신뢰구간 -0.81% ~ +1.05%), 사실상 0.
- 그러나 사전 추세 검정에서 서울과 부산의 도입 전 흐름이 달라(p ≈ 4.5e-83) 계획서의 규칙대로 **인과 해석은 보류**합니다.
- 가짜 도입일 추정치(최대 +3.3%)가 실제 추정치보다 큽니다. 이 설계는 3~5% 이내 효과를 계절 차이와 구분하지 못합니다.
- 다음 단계: 비교 도시를 늘려(합성통제) 평행추세를 개선.

## 실행 방법

```
pip install -r requirements.txt

python src/estimate.py --panel data/processed/station_month.csv --out results
python src/exploratory.py --panel data/processed/station_month.csv --out results   # 사전등록 밖 탐색
```

## 왜 계획서를 먼저 올렸나
결과를 본 뒤 분석 방법을 바꾸면 원하는 결론에 맞추게 될 수 있습니다. 그래서 가설, 사용 데이터, 모델, 판단 기준을 먼저 `plan.yaml`에 적어 커밋하고, 이후 변경은 git 기록과 아래 "계획 변경 기록"에 남깁니다.

## 데이터 출처 (공공데이터포털, 이용허락범위 제한 없음)
- 서울교통공사_1_8호선 역별 일별 시간대별 승객유형별 승하차인원 (data.go.kr/data/15099330), 반기 파일 5개(2022 하반기 ~ 2024 하반기)
- 부산교통공사_시간대별 승하차인원 (data.go.kr/data/3057229), 연도 파일 3개(2022 ~ 2024)
- 원본 CSV는 용량이 커서 저장소에 올리지 않습니다. 위 포털에서 받아 `data/raw/`에 `seoul_<날짜>.csv`, `busan_<연도>.csv` 이름으로 두면 `src/prepare.py`가 재현합니다.

## 데이터에서 발견한 점 (정리 단계 기록, 효과 추정 전)
- 인코딩이 CP949이고, 서울 호선 표기가 파일마다 `2`, `2.0`, `2호선`으로 다릅니다. 숫자만 뽑아 통일했습니다.
- 서울 2023년 상반기 파일에 호선이 비어 있는 행이 있습니다(굴포천 2023-03-07, 승차/하차 각 1행). 같은 역번호로 호선을 찾을 수 없어 제외했습니다(승차 1행).
- 부산 자료에는 호선 열이 없어 역번호 대역(1xx=1호선 ... 4xx=4호선)으로 호선을 정했습니다.
- 부산 합계 열과 시간대별 합은 모든 행에서 일치했습니다.
- 서울 8개 역-호선은 일부 월에만 있고, 승차 0으로 기록된 구간이 있습니다(`qc_report.txt`에 역 이름과 기간 기록).

## 계획 변경 기록
### 계획 보완 1 (2026-10-07, 효과 추정 실행 전)
`plan.yaml`에 주 분석 표본의 정의가 빠져 있어 보완합니다. 이 결정은 처치효과 추정치를 보기 전에 내립니다(정리 단계의 역별 월 수와 승차 0 여부만 본 상태).
- 주 분석 표본: 30개월(2022-07 ~ 2024-12) 모두 자료가 있고 월평균 평일 승차인원이 0보다 큰 역-호선만 사용(균형 패널).
- 보조 분석: 부분 기간 역을 포함한 불균형 패널(승차 0 달은 제외).
- 평일 정의: 월~금. 공휴일은 별도 목록 없이 포함하되, 중앙값 기반 결과(`median_weekday_boardings`)로 재추정해 영향을 확인한다.

### 계획 보완 2 (2026-10-07, 효과 추정 실행 전)
추정 코드를 쓰기 전에 아래 세부 규칙을 확정한다. 아직 어떤 처치효과 추정치도 보지 않았다.
- 주 모형: log(월평균 평일 승차인원) ~ 서울x사후 + 역-호선 고정효과 + 월 고정효과. 표준오차는 역-호선 군집.
- 사후 구간: 2024-02 ~ 2024-12. 2024-01(도입 달)은 DiD 추정에서 제외. 이벤트 스터디에서는 기준월을 2023-12(-1)로 두고 2024-01도 계수로 표시.
- 사전 추세 점검: 이벤트 스터디의 도입 전 월 계수가 모두 0이라는 가설의 군집-로버스트 Wald 검정.
- 이상치 규칙(보조 분석): 월 대비 월 로그 변화가 한 번이라도 ln(2) ≈ 0.693을 넘는 역-호선(약 2배 급변)을 제외하고 재추정.
- 가짜 도입일(placebo-in-time): 사전 기간(2022-07 ~ 2023-12) 안에서만, 가짜 도입 월 p를 2022-12 ~ 2023-08 사이로 바꿔가며(가짜 시작월 앞뒤로 최소 5개월/4개월 확보) 같은 모형을 추정한다. 실제 추정치의 절댓값이 가짜 추정치 분포에서 차지하는 순위를 보고한다. 표본이 작고 서로 겹치므로 공식 p값이 아니라 참고 지표로만 쓴다.
- 호선별: 서울 각 호선(1~8) 대 부산 전체.
- 재추정: 사전 12개월만, 사후 6개월만, 수준(level) 종속변수, 중앙값 기반 종속변수.
- 판단 기준: 사전 추세 검정에서 도입 전 계수가 명확히 0이 아니면(유의수준 5%에서 기각) 인과 해석을 보류하고 그 사실을 결과 첫머리에 쓴다.
